# Security audit — Carrera de Tiempo

**Date:** 2026-07-30  
**Scope:** OWASP Top 10 (web/API), network exposure, SQL injection, bot abuse  
**Stack:** NestJS + Prisma + Postgres + Socket.IO + Next.js PWA (Dokploy/Traefik)

## Executive summary

| Area | Status | Notes |
|------|--------|--------|
| SQL injection | **Pass** | All DB access via Prisma (parameterized). No `$queryRaw` / string SQL. |
| Port exposure / bots on open ports | **Pass (prod compose)** | DB has **no** host `ports:`; only `expose` on Docker network. Public edge is Traefik → `carrera_web:3000` only. |
| Injection (input) | **Hardened** | DTO validation + race code allowlist + nickname regex + body size cap. |
| Bot / flood | **Hardened** | Global + endpoint throttling; WS position throttle; geo rate limits. |
| AuthZ (host actions) | **Pass** | Host checked via `hostClientId` / `isHost` JWT claims. |

---

## Network / ports (bots)

### Production (`docker-compose.prod.yml`)

| Service | Host bind | Reachable from internet |
|---------|-----------|-------------------------|
| `carrera_db` | **none** (only `expose: 5432`) | **No** — Docker network only |
| `carrera_api` | **none** (only `expose: 3001`) | **No** — only via Next rewrites / internal DNS |
| `carrera_web` | **none** (only `expose: 3000`) | **Via Traefik** on `carrera.alore.dev` only |

Inside containers the API binds `0.0.0.0:3001` — that is normal for Docker; it is **not** published to the public NIC. Attack surface for bots is HTTPS on the web domain (Cloudflare + Traefik), not raw Postgres/API ports.

### Local (`docker-compose.yml`)

Postgres is published only as `127.0.0.1:5434` (loopback). Do **not** change this to `0.0.0.0`.

### Recommendations (ops)

1. Keep Cloudflare **proxied** (orange cloud) for L3/L7 bot filtering.  
2. Never add `ports: "5432:5432"` or public API binds.  
3. Optional: Cloudflare WAF managed rules (SQLi / bots) on `carrera.alore.dev`.

## SQL injection

- **Prisma Client only** for reads/writes (`findUnique`, `create`, `update`, `$transaction` of Prisma ops).  
- No raw SQL templates.  
- User-controlled fields: nickname, pin, destLabel, codes, coordinates — all validated and passed as bound parameters via Prisma.

**Verdict:** SQLi risk **low** with current data layer.

## OWASP-oriented findings & fixes applied

| ID | Category | Finding | Severity | Fix |
|----|----------|---------|----------|-----|
| A03 | Injection | Path/body params weakly typed | Medium | Stricter DTO: UUID v4, race code alphabet, nickname unicode allowlist, pin digits only |
| A04 | Insecure design | Race create/join/geo spamable | Medium | `@nestjs/throttler` global + stricter limits on create/join/geo |
| A05 | Misconfiguration | CORS fallback `true` in API | High (prod) | CORS **required** in production; methods/headers limited |
| A05 | Misconfiguration | Missing security headers on API | Low | `helmet` on Nest |
| A05 | Misconfiguration | Large JSON bodies | Medium | Body limit **32kb** |
| A01 | Access control | Host actions rely on clientId | Medium (by design, no accounts) | Keep host checks; rate-limit; optional future captcha |
| A07 | Auth | No accounts — room codes guessable | Low–Med | 6-char unambiguous alphabet (~1e9 space) + join rate limit |
| A10 | SSRF | Geo proxies Photon with user `q` | Low | Max query length, strip control chars; no user-supplied URL fetch |

## Rate limits (anti-bot)

| Scope | Limit |
|-------|--------|
| Global (default) | 120 req / min / IP |
| `POST /api/races` | 10 / min |
| `POST /api/races/:code/join` | 20 / min |
| `GET /api/geo/*` | 30–40 / min |
| `GET /api/health` | skipped (probes) |
| WS `race:position` | ~1 / 1.5–2 s per participant (existing) |
| WS max HTTP buffer | 16 KB |

`trust proxy` enabled so limits use real client IP behind Cloudflare/Traefik.

## Residual risks (accepted for MVP)

1. **No human captcha** — sophisticated bots can still create rooms slowly; mitigate with Cloudflare Bot Fight Mode if abused.  
2. **Host spoofing** — anyone who knows `hostClientId` UUID could act as host if they also obtained a token for that device; tokens are issued only after create/join.  
3. **Code enumeration** — rate-limited; monitor 404 rates on join.  
4. **OpenStreetMap / Photon dependency** — third party; rate-limited on our side.
